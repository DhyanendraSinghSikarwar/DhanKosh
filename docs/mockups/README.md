# Mockups

Self-contained HTML files for screens not yet built.

Rules:
- Use the app's theme tokens ([feature 28](../../memory/28_theming_customisation.md)); show light and dark.
- Dummy data only (no real names, amounts, accounts, UPI ids).
- Build approved mockups exactly; do not rewrite one without approval.
- Remove a mockup once its feature ships and a screenshot replaces it.
- Reference GIFs of the existing Kotlin app: [assets_reference/_screens_index.md](../../assets_reference/_screens_index.md).
